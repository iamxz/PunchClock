# Daka 手动验证清单

在 `/Applications/Daka.app` 上执行。注意：工作日 09:00 后启动会立即弹出全屏催打卡，属预期行为。

- [ ] 双击启动后，菜单栏出现图标，Dock 无图标。
- [ ] 菜单栏点开显示今日「上班打卡 / 下班打卡」状态、两个手动补打卡按钮、时间设置、自启状态。
- [ ] 用「调试：+10 分钟」把时间推进到 09:00 之后 → 全屏遮罩弹出，标题「该上班打卡了」。
- [ ] 遮罩上按 ESC、Cmd+W、Cmd+M、Cmd+H 均无反应。
- [ ] 点遮罩上的「上班打卡」→ 遮罩消失，菜单栏显示上班已完成时间。
- [ ] 再推进到 18:30 之后 → 遮罩标题「该下班打卡了」。
- [ ] 点「下班打卡」→ 遮罩消失。
- [ ] 上班和下班都欠账时，遮罩同时显示两个按钮，打完一个少一个。
- [ ] 有待办时菜单栏「退出 Daka」置灰；无待办时可正常退出。
- [ ] 遮罩出现时用 Cmd+Q 无法退出应用。
- [ ] 菜单栏手动补打卡按钮：未完成时可点；已完成时置灰。
- [ ] 「标记今天不打卡」→ 遮罩消失；跨天后自动恢复提醒。
- [ ] 多显示器：每个屏幕都出现遮罩，按钮位置正常。
- [ ] 遮罩出现时，拔插外接显示器 → 遮罩在新屏幕上立即出现（无需等待 2 分钟）。
- [ ] 遮罩出现时切到其它 App 的全屏 Space，遮罩仍置顶（2 分钟内自动重弹）。
- [ ] 合盖休眠 3 分钟再唤醒 → 立即弹出当前待办。
- [ ] 改系统时间跨越 09:00 → 提醒随之出现。
- [ ] 跨午夜（0 点后打开菜单栏）→ 菜单栏状态切到新的一天，不再显示昨天的完成状态。
- [ ] 设置里改上班时间为当前时间前一分钟 → 约一分钟后弹出遮罩。
- [ ] 重启/重新登录（工作日、上班未打卡）→ 立即弹出上班催打卡。
- [ ] 开机自启状态行显示正确；若系统要求批准，显示「需在系统设置中允许」且可打开设置。
- [ ] `~/Library/Application Support/Daka/data.json` 内容随操作更新且为合法 JSON。
