# Daka 手动验证清单

在 `/Applications/Daka.app` 上执行。工作日 09:30 后（或 18:30 后）启动会立即弹全屏催打卡，属预期行为。

## 基础

- [ ] 启动后菜单栏出现图标，Dock 也出现应用图标。
- [ ] 菜单栏面板只有：今日状态、打卡按钮、「控制中心」、桌宠开关（设置与统计在主窗口）。

## 窗口内温和提醒

- [ ] 08:59 → 无提醒；09:00 → 温和；09:29 → 温和。
- [ ] 温和时菜单栏图标为铃铛 `bell.badge`，状态行显示「窗口内待打卡」，并收到系统通知；**不弹全屏**。
- [ ] 温和时每 2 分钟重复通知（可临时把 `reminderIntervalSeconds` 调小以加快验证）。

## 过截止强制提醒

- [ ] 09:30 起菜单栏图标为警示 `exclamationmark.triangle.fill`，全屏遮罩「该上班打卡了」，并显示已欠时长。
- [ ] 全屏遮罩每 2 分钟重弹/置顶，ESC / Cmd+W / Cmd+M / Cmd+H 无效。
- [ ] 点「上班打卡」→ 全屏消失，状态显示已完成时间。
- [ ] 18:00 → 下班温和；18:30 → 下班全屏。
- [ ] 上班、下班都欠账时，全屏同时显示两个按钮，打完一个少一个。

## 通知权限

- [ ] 首次弹通知授权。
- [ ] 允许 → 温和通知可见。
- [ ] 拒绝 → 温和仅体现在菜单栏（图标/文字），全屏强制不受影响。

## 退出拦截（v8）

- [ ] 菜单栏面板 / 桌宠右键菜单 / 工具面板中都没有退出入口。
- [ ] 任何阶段（无任务、温和、强制）按 Cmd+Q 均无效，应用不退出。
- [ ] 设置页「应用 → 退出应用」弹确认框：点「取消」应用仍在；点「仍要退出」应用退出。
- [ ] 系统注销 / 关机 / 重启时应用正常结束，不卡关机。
- [ ] Cmd+Opt+Esc 强制退出仍可结束应用（已知限制，无法屏蔽）。

## 时间与系统事件

- [ ] 改系统时间跨越 09:00 / 09:30 / 18:00 / 18:30，提醒等级随之变化。
- [ ] 合盖休眠再唤醒 → 立即按当前等级提醒。
- [ ] 跨午夜打开菜单栏 → 状态切到新的一天，不再显示昨天。
- [ ] 全屏遮罩出现时拔插外接显示器 → 新屏立即出现遮罩。

## 定点启动

- [ ] `launchctl print gui/$(id -u)/com.xue.daka.schedule` 能看到服务与四个 `StartCalendarInterval`（09:00 / 09:30 / 18:00 / 18:30）。
- [ ] 退出应用后到点会被自动拉起（可临时把某个窗口时间设为 1 分钟后验证）。
- [ ] 已在运行时跳过，不产生第二个菜单栏图标，也不弹主窗口。

## 单实例

- [ ] 再次直接运行 `/Applications/Daka.app/Contents/MacOS/Daka` 不会出现第二个菜单栏图标。

## 数据

- [ ] `~/Library/Application Support/Daka/data.json` 为合法 JSON，且随操作更新。
- [ ] 旧版 `data.json`（含 `morningTime`/`eveningTime`）能平滑升级为新默认值，不触发损坏备份。

## v3：应用主窗口与统计

- [ ] Dock 出现 Daka 图标；双击或点 Dock 图标会打开主窗口。
- [ ] 主窗口关闭后应用仍在后台提醒；再点 Dock 图标或菜单栏「打开 Daka」可重新打开。
- [ ] 主窗口「统计」页显示「本月打卡 / 连续打卡 / 平均上班 / 缺卡」四张指标卡。
- [ ] 无打卡时长数据时统计页显示占位提示；有数据时显示每日上班时长柱状图。
- [ ] 柱状图范围可切 7 / 14 / 30 天。
- [ ] 主窗口「设置」页可改启用、工作日、4 个时间、今天不打卡，查看自启与定点状态，调试时间。
- [ ] 状态栏面板只剩：今日状态、打卡按钮、「控制中心」、桌宠开关；不再有设置与统计。
- [ ] 登录/定点拉起（带 `--background`）时不弹主窗口。
- [ ] 状态栏图标三态（勾 / 铃铛 / 三角）仍正确；禁用或休假当天状态显示「今日不提醒」。

## v4：重复打卡

- [ ] 同一天对同一项（上班/下班）可打卡多次；每次打卡都会追加记录。
- [ ] 状态行在重复打卡后显示次数，如「17:00（2 次）」；上班显示最早时间，下班显示最晚时间。
- [ ] 统计里的上班时长 = 下班最晚时间 − 上班最早时间。
- [ ] 上班、下班都打完后，菜单栏圆形按钮仍可打卡：12 点前补打上班，12 点后补打下班。
- [ ] 旧版 `data.json`（`morningDone`/`morningDoneAt` 单条记录）能平滑升级为打卡列表，不触发损坏备份。

## v5：最少工时（考勤规则）

- [ ] 下班打卡距当天最早上班打卡满「每日最少工时」（默认 8 小时）才算完成。
- [ ] 不满最少工时点下班 → 下班仍显示未完成，过下班截止后继续全屏催，可重复打卡直到满足工时。
- [ ] 当天没有上班打卡 → 下班打卡不算完成。
- [ ] 设置页「考勤规则」可改每日最少工时（1–12 小时，步进 0.5）；改后立即生效。
- [ ] 统计中的「上班时长」为 最晚合格下班 − 最早上班；不满最少工时的下班不计入完成/工时。
- [ ] 重复打卡次数在两行状态里可见（如「18:01（2 次）」）。

## v7：桌面宠物平台

- [ ] 桌面右下角出现桌宠（无边框、透明、置顶）；可拖动，重启后位置保留。
- [ ] 左键点击桌宠 → 气泡面板：今日概览（打卡状态）+ 工具入口 + 快捷长按打卡 + 控制中心/退出。
- [ ] 右键桌宠 → 菜单（打开控制中心 / 隐藏桌宠 / 退出）。
- [ ] 菜单栏可切换「显示/隐藏桌宠」；「控制中心」按钮打开主窗口。
- [ ] 控制中心左侧列出「打卡统计 / 喝水 / 护眼 / 久坐」，右侧显示所选工具的统计与设置；打卡可切「统计 / 设置」。
- [ ] 喝水/护眼/久坐显示「即将推出」。
- [ ] 打卡全部既有行为无回归（温和/全屏、重复打卡、最少工时、休假、定点启动）。

## v8：禁止随便退出 / 后台常驻

- [ ] 桌宠右键菜单为：打开控制中心 / 隐藏桌宠；无「退出 Daka」。
- [ ] 工具面板底部只有「控制中心」；无「退出」。
- [ ] 从设置页确认退出后进程消失；`pgrep -x Daka` 无输出。
- [ ] 从设置页取消退出后进程仍在，且继续按当前等级提醒。
