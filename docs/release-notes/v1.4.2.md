## 更新内容

本版把全屏提醒里的打卡按钮改成长按，避免一不留神就把卡打掉。

- **打卡按钮改为长按 3 秒**：按下后按钮中间会显示 3-2-1 倒计时，外圈进度环走满一圈才真正写入打卡；中途松手立即取消。
- **误触不会再有记录**：全屏提醒弹出时，只是想看下时间、临时切个窗口，碰到按钮也不会误打卡。
- **按住期间按 ESC 会真正中止**：遮罩收起的同时取消倒计时，不会在后台悄悄把卡打上。
- **按钮下方补了一行说明**：写着「长按圆形按钮 3 秒完成打卡」，第一次遇到时不用猜。

## 需要注意的变化

- 打卡按钮的操作方式和以前不同：以前点一下就打上，现在需要按住约 3 秒。菜单栏面板里的打卡按钮本来就是长按 3 秒，两个入口现在一致。
