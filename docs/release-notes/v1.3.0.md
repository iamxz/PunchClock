## 更新内容

本版新增**时间段请假**：请假不再只能「一整天」，可以只请下午两小时，也可以一次请三天。

- **日历右键即可新增请假**：选择起止日期与时间（精确到分钟），当天几小时或跨周末连休都能填，备注可选。同一格可再编辑、可整条取消（跨天请假一次撤销）。
- **请假直接抵扣应上班时长**：例如 9:00 上班、工时 9 小时，请假 16:00–18:00，那么 16:00 打下班卡就算正常出勤，进度环也会提前转满。上午请假同样把下班线顺延，不会要求你补齐已扣掉的工时。
- **日历上标「假」**：请假的日子显示紫色「假」字，鼠标悬停可看当天具体时段与时长；半天与全天都只标「假」，长短看提示。
- **请假期间安静**：请假时段内不再弹打卡提醒与喝水/久坐提醒，请假一结束立刻恢复（例如上午请假到 11:00，11:00 就会催上班卡）。
- **统计新增「本月请假」**：半天按 0.5 天折算，整月累加显示（如 `2.5 天`）。周末与法定节假日标「假」但不计入折算。
- **旧数据自动迁移**：之前用「今天不打卡（休假）」标记的日子，首次启动会自动转成一条整天请假，无需重录。

## 需要注意的变化

- **半天请假但一次卡都没打，现在算缺卡并会中断连续打卡**：旧版只要标记过「休假」就整天免打卡，新版按实际请假时长判断——只请了下午，上午仍需要打上班卡。
- 请假数据改存为新格式，**降级回旧版本将无法看到请假记录**，请谨慎回退版本。
