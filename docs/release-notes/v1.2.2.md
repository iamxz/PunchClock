## 更新内容

这一版引入了应用内通知与提醒确认机制，并重做了应用图标。

- **自绘 Toast 通知**：打卡、补卡、改时间等操作改为在界面右上角浮出提示，说明结果与还差多久，不再只靠系统通知。
- **退出前确认**：Cmd+Q、Dock 退出、应用内退出统一走确认框，会明确说明退出后不再提醒、当天漏卡不补。
- **健康提醒与全屏遮罩逻辑增强**：提醒触发更稳定，遮罩只承载考勤提醒。
- **测试面板（调试设置）**：「设置 → 测试面板」可预览各类提示的真实效果，便于确认提醒文案。
- **应用图标重做**：改为扁平风格，纯色圆角方块 + 白色四角星芒，Dock 与程序坞里更小尺寸也清晰。
